# DASC3240_final_project

# Repository Overview

## Purpose
This repository hosts the collaborative development of a Shiny application in RStudio.  
The app explores the relationship between **teen social media usage** and **mental health outcomes**, including stress, sleep, and overall well-being.

## Contents
- **data/**  
  Contains the raw Kaggle dataset and any cleaned versions prepared for visualization.

- **app.R**  
  The main Shiny application code, integrating user interface and server logic.

- **scripts/**  
  Supporting R scripts for data cleaning, preprocessing, and exploratory analysis.

- **www/**  
  Static assets such as CSS stylesheets, images, or custom JavaScript used in the app.

- **README.md**  
  Overview of the repository, setup instructions, and collaboration guidelines.

- **LICENSE**  
  Dataset and code licensing information.

- **.gitignore / .Rproj**  
  Project configuration and version control setup.

## Collaboration
The repository is managed via GitHub with proper branch usage, clear commit messages, and integration of contributions from all team members.

## Deployment
The Shiny app will be deployed on shinyapps.io (or RStudio Server).  
Instructions will be provided for external users to run the app locally using `runGitHub()` or access it online.
